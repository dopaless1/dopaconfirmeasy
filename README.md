# DopaConfirm 🚀
نظام متكامل ومستقل لإدارة تأكيد طلبات Shopify عبر WhatsApp مع ربط تلقائي بشركات الشحن (Starlink).

## 🌟 مميزات المشروع (Features)
- **تأكيد آلي عبر واتساب**: إرسال رسالة واتساب للعميل فور وصول الطلب من شوبيفاي مع زر لتأكيد الطلب.
- **تزامن مباشر مع Shopify**:
  - سحب الطلبات تلقائياً عبر Webhooks بمجرد إنشائها.
  - إضافة Tags في شوبيفاي بحالة الطلب (مثال: `WhatsApp: Confirmed`).
  - إلغاء الطلب في شوبيفاي إذا ألغاه العميل.
- **ربط بشركات الشحن (Starlink)**:
  - إرسال الطلبات المؤكدة تلقائياً لشركة الشحن.
  - مزامنة حالات الشحن (Scraping) لتعقب الشحنات (تم التسليم، فشل التوصيل، إلخ).
- **لوحة تحكم احترافية (Dashboard)**:
  - واجهة سهلة وسريعة تعمل بنظام Real-time (بدون الحاجة لعمل Refresh).
  - إحصائيات مالية (المبيعات المؤكدة، الملغية، قيد الانتظار).
  - إجراءات جماعية (تأكيد جماعي، إعادة إرسال رسائل جماعية).
  - كتابة ملاحظات داخلية لفريق العمل.
  - إرسال رسائل واتساب حرة (Custom Messages) مباشرة من الداشبورد.
  - تصدير الطلبات كملف Excel/CSV.
  - سجل زمني مفصل (Order Timeline) لكل طلب.
  - إشعارات صوتية عند وصول طلب جديد أو تأكيد عميل.
- **نظام حماية داخلي**: تسجيل دخول بكلمة مرور لحماية بيانات العملاء والمبيعات.
- **قاعدة بيانات سريعة ومجانية**: مبني على Turso (SQLite) لضمان السرعة الفائقة والاحتفاظ بالبيانات.

## ⚙️ بيئة العمل (Workflow)
1. **دخول الطلب**: يقوم العميل بإنشاء طلب على متجر Shopify.
2. **الاستقبال (Webhook)**: يقوم Shopify بإرسال الطلب فوراً إلى الخادم (Railway).
3. **إرسال واتساب**: يقوم الخادم بإرسال رسالة ترحيبية للعميل تحتوي على تفاصيل الطلب ورابط/زر للتأكيد باستخدام مزود (Green API).
4. **رد العميل**:
   - **إذا أكد العميل**: تتغير حالة الطلب إلى (مؤكد ✅)، ويتم إرساله تلقائياً لشركة الشحن (Starlink)، وتُضاف Tag لتأكيد الطلب في شوبيفاي.
   - **إذا ألغى العميل**: تتغير الحالة إلى (ملغي 🚫)، ويُحذف أو يُلغى الطلب في شوبيفاي.
5. **متابعة الشحن**: يمكن للموظف من الداشبورد مزامنة حالات الشحن آلياً، لتحديث حالة الطلب إلى (متسلم 📦) عند نجاح التوصيل.
6. **طلب التقييم**: يمكن للموظف إرسال رسالة للعميل بعد استلام الطلب لطلب تقييم الخدمة.

## 🛠️ كيفية التسطيب خطوة بخطوة (Setup Guide)

### الخطوة 1: تجهيز قاعدة البيانات (Turso)
1. افتح حساب في موقع [Turso.tech](https://turso.tech).
2. قم بإنشاء قاعدة بيانات جديدة (Database).
3. احصل على رابط قاعدة البيانات `Database URL` (يبدأ بـ `libsql://`).
4. احصل على التوكن `Auth Token`.

### الخطوة 2: إعداد تطبيق Shopify
1. اذهب إلى لوحة تحكم Shopify الخاصة بمتجرك.
2. انتقل إلى **Settings** > **Apps and sales channels** > **Develop apps**.
3. قم بإنشاء تطبيق جديد (مثال: `DopaConfirm App`).
4. اضغط على **Configure Admin API Scopes** وقم بإعطاء الصلاحيات التالية:
   - `write_orders`, `read_orders`
   - `write_customers`, `read_customers`
5. اضغط **Install App** للحصول على **Admin API access token** (يبدأ بـ `shpat_...`).
6. قم بتفعيل الـ Webhooks في التطبيق ليقوم بإرسال الطلبات إلى رابط السيرفر الخاص بك `https://your-domain.up.railway.app/webhook/shopify`.

### الخطوة 3: إعداد مزود الواتساب (Green API)
1. سجل في [Green API](https://green-api.com/).
2. قم بإنشاء Instance وربطه برقم الواتساب الخاص بك عبر مسح الـ QR Code.
3. انسخ الـ `idInstance` والـ `apiTokenInstance`.
4. داخل لوحة تحكم Green API، تأكد من تفعيل **Webhooks** للرسائل الواردة (Incoming messages) واجعل الرابط:
   `https://your-domain.up.railway.app/webhook/greenapi`

### الخطوة 4: الرفع على الخادم (Railway)
1. قم بإنشاء حساب في [Railway.app](https://railway.app).
2. قم بربط حساب الـ GitHub الخاص بك واختر المستودع (Repository) الذي يحتوي على هذا الكود.
3. اذهب إلى قائمة **Variables** في Railway وأضف المتغيرات التالية:
   ```env
   # إعدادات قاعدة البيانات
   TURSO_DATABASE_URL=libsql://your-db-url.turso.io
   TURSO_AUTH_TOKEN=your-turso-token

   # إعدادات شوبيفاي (تستخدم لتأمين الويب هوك)
   SHOPIFY_WEBHOOK_SECRET=your-shopify-webhook-secret

   # حماية الداشبورد (كلمة المرور للدخول)
   ADMIN_PASSWORD=your-secure-password
   
   # بورت التشغيل (Railway يحدده تلقائياً)
   PORT=3000
   ```
4. سيبدأ Railway في بناء وتشغيل المشروع تلقائياً.

### الخطوة 5: ضبط الإعدادات الداخلية من الداشبورد
1. بعد نجاح تشغيل السيرفر، ادخل إلى رابط الداشبورد على المتصفح: `https://your-domain.up.railway.app`.
2. قم بتسجيل الدخول بكلمة المرور التي حددتها في `ADMIN_PASSWORD` (أو `admin123` إذا لم تحددها).
3. اذهب إلى **⚙️ الإعدادات** في الداشبورد وأدخل:
   - رابط متجر شوبيفاي (`your-shop.myshopify.com`).
   - الـ Access Token الخاص بشوبيفاي.
   - بيانات الـ Green API (`idInstance` و `apiTokenInstance`).
   - قوالب رسائل الواتساب.
4. اضغط حفظ. مبروك! نظامك الآن يعمل ومتصل بالكامل.

## ❓ ماذا يحدث إذا تكرر تسجيل المتغيرات (Env Vars)؟
يتم الاعتماد في هذا المشروع على مبدأ **"المتغيرات المباشرة هي الأقوى"**.
- إذا قمت بكتابة متغير مثل `ADMIN_PASSWORD` داخل إعدادات (Variables) في منصة Railway، **فهذا هو الذي سيتم استخدامه دائماً**. الكود يعطي الأولوية لما هو مسجل في Railway متجاهلاً أي كلمة مرور افتراضية (مثل `admin123`) مكتوبة داخل الكود.
- الإعدادات المرنة (مثل قوالب الرسائل وتوكن شوبيفاي) يتم حفظها في قاعدة البيانات (Turso) عبر الداشبورد لتسهيل تعديلها دون الحاجة لعمل Restart للسيرفر.
